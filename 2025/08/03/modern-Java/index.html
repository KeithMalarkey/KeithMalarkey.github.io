# 语法盐

定义：
语法盐是指编程语言中故意设置的语法限制，目的是增加代码的严谨性，防止错误，但可能会让代码更冗长或难写。
特点：

  • 提高代码安全性，减少潜在错误。
  • 可能降低开发效率（需要更多样板代码）。
