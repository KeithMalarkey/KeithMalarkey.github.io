# 代码解析

# 基本数据类型

在 Java 中，基本数据类型（如 int、float、char 等）是按值传递的。当我们调用 swap(a, b) 时，实际上传递的是 a 和 b 的值的副本。函数内部对 a 和 b 的修改不会影响到原来的变量。

# 引用数据类型

# 分析

  • 对于引用数据类型，对象变量存储的是堆内存地址的引用值，非对象本身。
  • 调用 swap(p1, p2) 时，传递的是 p1 和 p2 引用的副本（即地址值的拷贝）。
  • 方法内交换的是副本的引用，不影响外部的原始变量。
