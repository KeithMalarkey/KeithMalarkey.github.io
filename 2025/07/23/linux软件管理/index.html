# npm

npm （Node Package Manager）是 Node.js 的默认包管理工具，用于下载、安装、管理和发布 JavaScript 代码模块（称为 "包" 或 "package"）。它是全球最大的开源软件注册中心，拥有超过 200 万个可复用的代码包。

# npm 的核心功能

功能说明
安装依赖包通过 npm install 下载和管理项目所需的库（如 React、Vue、Express）。
管理项目依赖记录依赖项到 package.json，确保团队协作时环境一致。
运行脚本通过 npm run 执行自定义命令（如启动服务器、打包代码）。
发布自己的包可将自己写的模块发布到 npm 供他人使用。
版本控制支持语义化版本（^1.2.3），避免依赖冲突。

# git 😉

git 是一个分布式版本控制系统，用于跟踪文件的更改，特别是源代码文件。它允许多个开发者协同工作，管理项目的历史记录。git 的逻辑存储划分为三个主要部分：工作区（Working Directory）、暂存区（Staging Area）和版本库（Repository）。因此，git 的工作流主要是在三个区域上的操作。

在 nvim/vim 等编辑器中，git 通常通过插件集成，提供版本控制功能。比如 lazygit 是一个基于终端的 Git UI 工具，提供了更友好的界面来管理 Git 仓库。在 vscode 这样的轻量级 IDE 中，也提供了很多可视化的 git extensions (如 git graph)。

# 团队协作工作流

  1. 主分支模型
  • main / master : 稳定生产代码
  • develop : 开发分支，集成所有功能分支
  • feature/* : 功能分支，从 develop 分支创建，完成后合并到 develop
  • release/* : 发布分支，从 develop 创建，准备发布到 main
  • hotfix/* : 紧急修复分支，从 main 创建，修复后合并到 main 和 develop
