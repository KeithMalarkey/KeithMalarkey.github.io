# pacman

pacman 是 Arch Linux 及其衍生发行版的包管理器，用于安装、更新和删除软件包。它使用 .pkg.tar.zst 格式的软件包。

除了 pacman 外，Arch Linux 还提供了 AUR（Arch User Repository），这是一个由社区维护的软件包仓库，用户可以通过 AUR 工具（yay、paru）来安装和管理 AUR 中的软件包。

# 基本语法结构

# operation

  • -S (Sync)：同步包。软件包直接从远程存储库安装，包括所需的所有依赖项运行这些包。例如， pacman-S qt 将下载并安装 qt 和所有它所依赖的包。如果一个包名称存在于多个存储库中，则可以显式指定存储库明确要安装的软件包: pacman-S testing/qt 。您还可以指定版本要求： pacman -S “bash>=3.2” 。
  • -R (Remove)：从系统中删除软件包。也可以指定要删除的组，在这种情况下，该组中的每个包都可以删除将被移除。属于指定包的文件将被删除数据库将被更新。除非使用 --nosave 选项，否则大多数配置文件将以.pascave 扩展名保存。
  • -U (Update)：从同步仓库更新 / 安装包到系统，这个同步仓库可以是制定的 url 或文件路径。处理逻辑： remove-then-add 。
  • -Q (Query)：查看包信息。查看已安装软件包的详细信息，包括版本、大小、安装日期等。可以使用 -i 选项查看详细信息，使用 -l 列出文件，使用 -s 搜索软件包。
  • -T (Deptest)：验证指定包是否满足依赖关系。in a word, 就是看 dependencies 是否完整。没有输出说明万事大吉，有输出就是依赖不完整。
  • -F (File)：在已安装的软件包或远程仓库中搜索特定文件。
  • -D : 对包数据库进行操作。此操作允许您修改 pacma 中已安装软件包的某些属性的数据库。它还允许您检查数据库的内部一致性。
  • -V : 显示版本
  • -h ：帮助

# yay & paru

考虑到 yay 和 paru 和 pacman 的用法非常相似，这里就不再赘述了。它们是 AUR 的包管理工具，提供了更方便的 AUR 包安装和管理功能。
它们的主要区别在于：

  • yay ：基于 pacman ，提供了 AUR 支持，并且支持交互式安装和更新。它的命令行界面与 pacman 非常相似，易于上手。
  • paru ：也是基于 pacman ，但提供了更丰富的功能和配置选项。它支持异步下载、自动清理缓存等功能，并且提供了更好的 AUR 支持。

了解一下 makepkg ，它是 AUR 的构建工具，用于从 AUR 源代码包构建和安装软件包。它通常与 yay 或 paru 一起使用。常见 makepkg 的命令包括： makepkg -si （构建并安装软件包）、 makepkg -s （仅构建软件包）、 makepkg -p <build-script> 等。如果你没有制定 build-script ，则默认使用 PKGBUILD 文件。因此， makepkg 常常在 PKGBUILD 文件所在的目录中运行。( PKGBUILD 是一个 shell script)

# curl

curl （Client URL）是一个强大的命令行工具，用于在 Linux/Unix 系统中传输数据。它支持多种协议，包括 HTTP、HTTPS、FTP、SFTP 。

# 常见 options

选项作用示例
-v显示详细请求 / 响应过程（调试）curl -v https://example.com
-i包含响应头在输出中curl -i https://example.com
-I仅显示响应头（HEAD 请求）curl -I https://example.com
-L跟随重定向（默认不跟随）curl -L http://example.com
-u认证（用户名：密码）curl -u user:pass https://api.com
-k忽略 SSL 证书验证（不安全）curl -k https://self-signed.bad
-x使用代理curl -x http://proxy:8080 https://example.com
-A设置 User-Agentcurl -A "MyBot/1.0" https://example.com

# apt/apt-get

apt 和 apt-get 是 Debian 和 Ubuntu 系统的包管理工具，用于安装、更新和删除软件包。它们使用 .deb 格式的软件包。

# apt 和 apt-get 的区别

工具说明
apt新的命令行工具，集成了 apt-get 和 apt-cache
apt-get传统的包管理工具，功能更全面但不够简洁
apt-cache用于查询软件包信息，通常不直接用于安装

# apt 的常用命令

命令作用
apt update更新软件包索引
apt upgrade升级所有已安装的软件包
apt install <package>安装指定软件包
apt remove <package>卸载指定软件包
apt search <keyword>搜索软件包
apt show <package>显示软件包详细信息
apt autoremove自动删除不再需要的依赖包
apt list --installed列出所有已安装的软件包
apt list --upgradable列出可升级的软件包
apt full-upgrade升级系统，处理依赖关系更复杂的升级
apt edit-sources编辑软件源列表

# npm

npm （Node Package Manager）是 Node.js 的默认包管理工具，用于下载、安装、管理和发布 JavaScript 代码模块（称为 "包" 或 "package"）。它是全球最大的开源软件注册中心，拥有超过 200 万个可复用的代码包。

# npm 的核心功能

功能说明
安装依赖包通过 npm install 下载和管理项目所需的库（如 React、Vue、Express）。
管理项目依赖记录依赖项到 package.json，确保团队协作时环境一致。
运行脚本通过 npm run 执行自定义命令（如启动服务器、打包代码）。
发布自己的包可将自己写的模块发布到 npm 供他人使用。
版本控制支持语义化版本（^1.2.3），避免依赖冲突。

# git 😉

git 是一个分布式版本控制系统，用于跟踪文件的更改，特别是源代码文件。它允许多个开发者协同工作，管理项目的历史记录。git 的逻辑存储划分为三个主要部分：工作区（Working Directory）、暂存区（Staging Area）和版本库（Repository）。因此，git 的工作流主要是在三个区域上的操作。

在 nvim/vim 等编辑器中，git 通常通过插件集成，提供版本控制功能。比如 lazygit 是一个基于终端的 Git UI 工具，提供了更友好的界面来管理 Git 仓库。在 vscode 这样的轻量级 IDE 中，也提供了很多可视化的 git extensions (如 git graph)。
